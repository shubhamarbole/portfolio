# Shubham Arbole — Personal Portfolio

A modern, high-performance developer portfolio built with React 18, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Responsive Hero Section**: Oversized fluid typography (`SHUBHAM ARBOLE`) with an interactive mouse-tracking 3D magnet portrait.
- **Dual Horizontal Showcase**: Smooth endless marquee scrolling in opposing directions featuring 4 live production projects.
- **Scroll-Driven Animated About**: Character-by-character scroll reveal text highlighting academic background and software engineering internships.
- **Interactive Skills Section**: Clean white card surface mapping 5 core software development domains.
- **Sticky Stacking Project Cards**: Framer Motion `useScroll` card compression with interactive in-card image galleries and full-screen lightbox modal.
- **Contact & Footer**: Direct email links, resume download (`/resume.pdf`), and social profile integration.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Animations & Physics**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite 6

## 💻 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/shubhamarbole/portfolio.git

# 2. Navigate to project directory
cd portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

## 🏗️ Production Build

```bash
npm run build
```
